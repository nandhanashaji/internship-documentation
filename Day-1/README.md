 Learnings

The first day of the internship focused on understanding Git and GitHub. Git is a version control system used to track changes in files, while GitHub is a platform used to host and collaborate on Git repositories.

I learned about repositories, commits, branches, pull requests, issues, and README files. These concepts help developers manage project versions and collaborate effectively with team members.

The session provided a foundation for understanding software development workflows and project documentation using GitHub.
